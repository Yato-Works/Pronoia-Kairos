  reconciliation checklist`)。このコミットの内容を基準として検証します。

## 依頼すること (4項目)

`docs/REPRODUCE.md` の手順だけを頼りに、次の4点を確認してください。

1. クリーンな環境から **CPU テスト 279件** を再現できる (`REPRODUCE.md` §1)。
2. **GPU テスト** を実行できる (`§2`)、あるいは GPU が無い場合に
   「GPU テスト・M4 完走は任意である」という制約を文書から理解できる。
3. 実行した各節の**生成成果物** (`artifacts/phase6/` の出力) が
   `REPRODUCE.md` の表の説明どおりである (`§3`-`§6`)。
4. **README に書かれた数値と成果物の数値が一致している**。

## CPU 再現性と GPU 再現性は別々に評価してください

CPU テスト279件が通過しても、それだけで RTX 3050 での M4 実験を再現
したことには**なりません**。以下のように区別します。

### A. 完全一致を要求する項目 (決定論・環境非依存)

| 項目 | 期待値 | 由来 |
|---|---|---|
| CPU テスト | `279 passed, 1 deselected` | シード固定・決定論 |
| README ↔ 正本 JSON 照合 | 14項目・不整合 0 (`RELEASE_CHECKLIST.md` 第3項) | 静的照合 |
| MC4 adjudication 再生成 (`§4`) | 出力 JSON が保存済みと一致 (元基準 NOT PASSED / 変更後 passed / Run A 10/428, B 12/428) | 保存 traces からの再計算は決定論 |
| M3 shuffle 再生成 (`§6`) | verdict `supported`、確認的 positive 6/8 家族、MC 全通過 (数値比較は ±1e-6) | シード固定 |
| GPU テストの位置づけ理解 | GPU 無しで §2 が deselected/任意と理解できる | 文書理解 |

### B. 環境差を考慮して比較する項目 (GPU 実測)

| 項目 | 要求すること | 要求しないこと |
|---|---|---|
| GPU テスト (`§2`) | 同一 GPU **内**での「キャッシュあり/なし」トークン列一致 (MC0) として実行・記録 | 別 GPU 間でのトークン列一致 |
| M4 実行 (`§3`, 約25分) | 手順・指標定義・4段階判定の構造が文書どおり実行できること、生成物の形式が説明どおりであること | **pooled +2.66% / +2.08% の数値再現** — GPU 型・クロック・driver により変動するため。差が出た場合は環境差として記録してください |

- 検証者が同じ **RTX 3050 + 0.5B (revision `7ae5576`) + eager** の
  環境である場合、pooled 値は同一に**なり得るが必須ではない**。
  差異があれば測定条件 (GPU 時計・温度・他プロセス) と共に記録してください。
- 観測した GPU・HW 条件は、`RELEASE_CHECKLIST.md` 第4項の記録欄に
  別項目 (CPU 側/GPU 側) で記入してください。

## 記録してほしいこと

| 記録項目 | 内容 |
|---|---|
| 環境 | OS / Python / torch / transformers / GPU (無しでも可) |
| 実行コマンド | `REPRODUCE.md` に従って実行したコマンドを原文で |
| 実行結果 | 各節の出力・終了コード・生成物の一覧 |
| 失敗の有無 | 失敗があれば上記に加えて全文ログ |

記入先: **`docs/RELEASE_CHECKLIST.md` 第4項**の記録欄 (直接 push でも、
貼り付け依頼でも構いません)。

## 問題が起きた場合のプロトコル (重要)

1. **先に記録を保全する** — コマンド、出力全文、環境を保存してから
   何も修正しない。
2. 原因を調査する (文書不足か、環境差か、バグか)。
3. 修正は**記録の後**に行い、修正したコミットを追跡できるようにする
   (**無言修正は禁止**)。

第三者である必要があります。
